
🔐 ATmega32 Password Door Lock

 Overview

This project is a password-based electronic door lock system developed using the **ATmega32 microcontroller**.

The system allows a user to enter a password using a keypad. The entered password is checked by the microcontroller, and access is granted when the correct password is entered.
